Side project

An open-source version of the go-live review I run at work, built as a tool any AI assistant can use.

Open sourcePythonModel Context ProtocolCI

Integration Sign-off MCP

A gateway-agnostic MCP server that reviews a merchant’s payment integration before go-live. Ask Claude or any MCP client to “run a go-live review for Acme Travel” and it checks the integration, records evidence and lists exactly what the merchant must fix.

  • Sends signed and deliberately bad webhooks to catch missing signature checks and replay gaps
  • Reads API logs for missing idempotency keys, double-charge retries and card data in traffic
  • Guides sandbox flows for success, failure, pending, refunds and amount tampering
  • Scans code for hard-coded secrets, float money and trusting ?status=success
  • Writes a report with fixed decision rules and a signed copy that detects later edits
