Project

’26

Integration Sign-off MCP

An open-source, gateway-agnostic MCP server that reviews a merchant’s payment integration before go-live. Ask Claude or any MCP client to “run a go-live review for Acme Travel” and it walks through the checks, records evidence and lists exactly what the merchant must fix.

  • Sends signed and deliberately bad webhooks to catch missing signature checks, replay gaps and duplicate-delivery bugs.
  • Reads API logs for missing idempotency keys, double-charge retries, rupee-vs-paise amounts and card data in traffic.
  • Guides sandbox flows for success, failure, pending, refunds and amount tampering, each backed by evidence.
  • Scans code for hard-coded secrets, unverified webhook handlers, float money and trusting ?status=success.
  • Applies fixed decision rules and writes a report with a SHA-256/HMAC-signed copy that detects later edits.
